# واصل — تطبيق الزبون (نموذج أولي)

تطبيق توصيل للزبون مكتوب بـ **Kotlin + Jetpack Compose**، كله بالعربي ومن اليمين لليسار.
هذه نسخة تجريبية تشتغل ببيانات وهمية (بدون خادم) حتى نشوف التصميم وطريقة الاستخدام.

## الشاشات
- **الرئيسية**: بحث بالمنتجات والمتاجر، أقسام، "طلب خاص"، والمتاجر مرتبة حسب وقت الوصول.
- **المتجر**: قائمة المنتجات حسب الأقسام، مفضلة للمنتجات، إضافة للسلة.
- **السلة والدفع**: عنوان التوصيل، الدفع نقداً، ملاحظة للمتجر، المجموع.
- **تتبع الطلب**: خريطة OpenStreetMap، شريط تقدّم، رمز تسليم من 4 أرقام، معلومات السائق.
- **نشاطي**: الطلبات الحالية والسابقة مجمّعة بالشهر مع مجموع الصرف، و"اطلب مرة ثانية".
- **حسابي**: العناوين، المفضلة، إعدادات الإشعارات.

## البنية
```
app/src/main/java/iq/wasel/customer/
├── AppViewModel.kt   حالة التطبيق + محاكاة دورة حياة الطلب
├── AppRoot.kt        التنقل، الشريط السفلي، زر السلة العائم
├── data/             النماذج والبيانات التجريبية
└── ui/               الشاشات والعناصر المشتركة والثيم
```

## البناء
كل دفع (push) يبني APK تلقائياً على GitHub Actions. التحميل من تبويب **Actions** ← آخر تشغيل ← **Artifacts**.

محلياً (يحتاج Android SDK):
```
gradle assembleDebug
```
